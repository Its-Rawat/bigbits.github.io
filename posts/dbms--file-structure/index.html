B-Tree⌗

🌳 B-Tree Nomenclature⌗

  • Order (m) → max children = m
  • Max keys → m − 1
  • Min keys (non-root) → ⌈m/2⌉ − 1
  • Children vs Keys → keys = children − 1
  • Root → minimum 1 key
  • Internal node → has children
  • Leaf node → no children
  • All leaves → same level (balanced)
  • Height → O(logₘ n)
