📘 Java Stream API⌗

🔹 What is Stream API?⌗

  • Introduced in Java 8
  • Used to process collections (like List, Set) in a functional and declarative style
  • Streams are not data structures — they don’t store data
  • Allows for pipelining operations (chaining of multiple operations)

🔹 Stream Lifecycle⌗

  1. Source: From a Collection or array
  2. Intermediate Operations: Transformations (lazy)
  3. Terminal Operation: Triggers the processing (eager)

🔹 Stream Creation⌗ 

List<String> list = Arrays.asList("a", "b", "c");
Stream<String> stream = list.stream();

Stream<Integer> stream = Stream.of(1, 2, 3, 4);

🔹 Intermediate Operations⌗

Method Description
filter(Predicate) Filters elements
map(Function) Transforms elements
flatMap(Function) Flattens nested structures
sorted() / sorted(Comparator) Sorts elements
distinct() Removes duplicates
limit(n) Limits output to n items
skip(n) Skips first n elements
peek() For debugging/side-effects

🔹 Terminal Operations⌗

Method Description
collect() Collects result into list, set, map
forEach() Performs action on each element
toArray() Converts to array
reduce() Reduces to a single value
count() Counts elements
anyMatch() / allMatch() / noneMatch() Matching conditions
findFirst() / findAny() Finds element

🔹 Collectors⌗ 

Collectors.toList()
Collectors.toSet()
Collectors.toMap()
Collectors.joining(", ")
Collectors.groupingBy()
Collectors.partitioningBy()

🔹 Examples⌗

✅ Filter numbers greater than 10⌗ 

List<Integer> result = list.stream()
    .filter(x -> x > 10)
    .collect(Collectors.toList());

✅ Convert to uppercase⌗ 

List<String> result = list.stream()
    .map(String::toUpperCase)
    .collect(Collectors.toList());

✅ Get first 5 sorted items⌗ 

list.stream()
    .sorted()
    .limit(5)
    .forEach(System.out::println);

✅ Group employees by department⌗ 

Map<String, List<Employee>> byDept = employees.stream()
    .collect(Collectors.groupingBy(Employee::getDepartment));

🔹 Advanced Operations⌗

🔁 Reduce Example⌗ 

int sum = list.stream()
    .reduce(0, (a, b) -> a + b);

📦 FlatMap Example⌗ 

List<List<Integer>> listOfLists = Arrays.asList(
    Arrays.asList(1, 2),
    Arrays.asList(3, 4)
);

List<Integer> flatList = listOfLists.stream()
    .flatMap(List::stream)
    .collect(Collectors.toList());

🧠 Tips⌗

  • Streams can only be used once (they get consumed after a terminal op)
  • Avoid modifying external mutable state inside streams
  • Use parallelStream() for parallel processing (only when necessary)

📝 Practice Questions⌗

✅ Easy⌗

  1. Filter even numbers from a list of integers.
  2. Convert a list of strings to uppercase.
  3. Count the number of empty strings in a list.
  4. Remove null values from a list.

🔁 Medium⌗

  1. Given a list of names, return names starting with “A”, sorted alphabetically.
  2. Return the average of a list of integers.
  3. Get a list of distinct elements from a list.
  4. Group a list of employees by department (using Collectors.groupingBy).

🧩 Advanced⌗

  1. Find the second highest number in a list.
  2. Flatten a list of lists of integers into a single list.
  3. Partition a list of integers into even and odd numbers.
  4. From a list of Person objects, get names of all adults (age > 18), sorted by age.
