🔢 Number System Recap⌗

If you don’t know Number Systems, here’s a quick recap.

Decimal Number⌗

In C, an integer constant without a prefix is treated as a decimal constant.

printf("%d", 40);
Binary Number Calculation⌗ 
Binary Number -> 0b1111

  1    1    1    1
  ↓    ↓    ↓    ↓
 2³   2²   2¹   2⁰

= 1×8 + 1×4 + 1×2 + 1×1
= 8 + 4 + 2 + 1
= 15
Octal Number Calculation⌗ 
Octal Number-> 014

014₈
= 1 × 8¹ + 4 × 8⁰
= 1 × 8 + 4 × 1
= 8 + 4
= 12₁₀
Hexadecimal Number Calculation⌗ 
Hexadecimal -> 0x

0x10₁₆
= 1 × 16¹ + 0 × 16⁰
= 1 × 16 + 0 × 1
= 16

Signed and Unsigned Number⌗

example: 2s compliment Integer Interpretation 1111 (Signed) -1x2^3 + 1x2^2 + 1x2^1

11111 (UnSigned) 1x2^3 + 1x2^2 + 1x2^1

2’s Complement — Signed Integer⌗
  • MSB (Most Significant Bit) = 0 → Positive
  • MSB = 1 → Negative
  • MSB weight = -2ⁿ⁻¹
  • Other bits have normal positive weights.

Example: 4-bit 1111⌗ 

Weights: -8  4  2  1
Bits:     1  1  1  1

= -8 + 4 + 2 + 1
= -1

Range of a Integer –> -2^n-1 to 2^n-1

`+, -, *, /, % "

C Operator Precedence — Short⌗
Priority Operators Associativity
1 () Left → Right
2 ++ -- ! ~ Right → Left
3 * / % Left → Right
4 + - Left → Right
5 < <= > >= Left → Right
6 == != Left → Right
7 && Left → Right
8 ` ` Left → Right
9 = += -= *= /= Right → Left

Higher priority = evaluated first.

* / % have same precedence → evaluate left to right.
